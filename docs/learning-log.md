# Learning log

Written by the owner, in the owner's own words. This is the source for interview answers. Agents may add questions here but must not write the owner's summaries.

## How to use

After each sprint, add an entry:

- What I built (three lines)
- Why I chose it (the main decision and the alternative I rejected)
- What I would change
- Five questions an interviewer could ask, and my answer to each (spoken once out loud, then written)
- Keep, stop, change (one line each)

## Template

```
## Sprint N: <name> (<date>)

Built:
Why:
Would change:

Questions and answers:
1.
2.
3.
4.
5.

Retro: keep / stop / change
```
